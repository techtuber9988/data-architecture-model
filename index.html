Immutable Versioning

Append-only history ensures that every change is preserved. No updates, no deletions, just a perfect trail of evolution.

Workspace Isolation

Native multi-tenancy via opaque workspace partitioning. Secure, scalable, and optimized for cloud-native deployments.

Role-Based Access

Granular permission model (Viewer, Editor, Admin) enforced at the database level for uncompromising security.

Threaded Discussions

Self-referential comment structures allowing deep, threaded conversations directly tied to document versions.

Compliance Audit Log

An append-only event store that records every mutation. JSONB payloads keep your audit trail rich and searchable.

Smart Tagging

Workspace-scoped labels with many-to-many relationships for powerful document organization and filtering.

A lean, relational design optimized for PostgreSQL. Every table is strategically indexed to handle millions of records without latency.

Developer Experience

Clean queries. Strict constraints. Zero ambiguity.

query_latest_version.sql 
SELECT d.id, d.slug, d.title, dv.body
FROM documents d
JOIN document_versions dv
  ON dv.document_id = d.id
  AND dv.version = (
      SELECT MAX(dv2.version)
      FROM document_versions dv2
      WHERE dv2.document_id = d.id
  )
WHERE d.slug = $1
  AND d.workspace_id = $2;
